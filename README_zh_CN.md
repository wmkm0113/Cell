# Cell.js

Cell.js 是一个使用 ECMAScript6 的轻量级、数据驱动的 JavaScript 框架，用于构建完整的网站，**具有最小的依赖性**，并且没有繁重的框架。

## 为什么选择 Cell.js ？

现代 UI 框架很强大，但它们也有成本： 
- 大型依赖树 
- 构建管道和捆绑器 
- 复杂的运行时抽象 
- 期维护开销 

Cell.js 专为以下环境而设计： 
- 不想引入过多的依赖包 
- UI 要求得到明确定义和控制 
- 使用数据构建现代网站 
- 国际化支持的简单解决方案

## Cell.js 是什么 

- 数据驱动的 UI 渲染 
- 用于组装 UI 组件的小型运行时 
- 常用 Web 组件、图表元素和数据加密功能的解决方案 
- 与框架无关（无 React、Vue、Angular）

## Cell.js 不是什么

- 虚拟 DOM 框架 
- React 或 Vue 的替代品 
- 大型、无界 UI 生态系统的解决方案

## 设计原则 

- **最小依赖性**  
  Cell 在设计上避免了外部框架和大型库。 
- **配置优先**  
  UI 使用结构化配置而不是 JSX 或模板以声明方式进行描述。 
- **可预测的渲染** 
  没有隐藏的生命周期魔法。渲染行为是明确且确定的。 
- **受控范围单元** 
  针对已知的 UI 模式，而不是任意应用程序逻辑。

## 核心概念 

- **Cell.js 定义**  
  Cell.js 是 UI 元素的声明性描述。 
- **组件类型**  
  内置组件，例如菜单、幻灯片、消息列表、详细信息等。 
- **渲染器**  
  JSON 数据转换为实际的 DOM 输出。为现有DOM元素添加一些属性，可以增强现有DOM元素对配置数据的支持。 
- **国际化**  
  只需两步即可实现网站国际化。 
- **组合**  
  Cell,js 可以嵌套以构建完整的界面。 
- **安全性**  
  支持主流加密方式，为互联网数据安全提供更好的保障。

## 如何开始 
如果你想尝试使用Cell.js，只需要在head标签中添加一行代码，将{version}替换为你想要的版本代码。
```javascript
<script src="https://cdn.jsdelivr.net/gh/wmkm0113/Cell@{version}/core/Cell.js" type="module"></script>
```

## 你应该使用 Cell.js 吗？

如果满足以下条件，请使用 Cell.js： 
- 您想要最小的 UI 运行时 
- 您控制 UI 要求 
- 您需要为网站添加国际化支持 

如果满足以下条件，请勿使用 Cell.js： 

- 您需要一个由第三方组件组成的大型生态系统 
- 您需要复杂的状态管理
